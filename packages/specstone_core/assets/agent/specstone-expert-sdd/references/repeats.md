# Repeated rules and old cites

For `specstone-bootstrap-prd` and `specstone-bootstrap-spec`. Give each link the form `confirm-links.md` gives for
rule 7; each write leaves a draft.

- `cite_unlinked`: rewrite the cite as a link to the one doc or item its text means.
- `batch: repeats` holds the `check --repeats` groups with an item in a doc your skill takes: under `prds/` or
  `measurements/` for `bootstrap-prd`, under `specs/` for `bootstrap-spec`.
- A group stating one rule: keep the item in the doc owning its subject, replace each other copy in your skill's docs
  with a link to it, and name the owner in each draft's reason.
- A group not stating one rule: keep each item and report the group as kept.
- A statement the procedure moved into a section that now repeats another doc's merges the same way.
